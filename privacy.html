Privacy

Last updated: 14 November 2026.

MetricStack is a static website. The calculators run entirely in your browser using HTML, CSS and JavaScript that we host with the pages. The numbers you type are not sent to a server operated by AHM Global, and they are not saved in a database we control.

What we do not do

  • We do not ask you to create an account or leave an email address to use a tool.
  • We do not set analytics, advertising or social-media tracking cookies.
  • We do not embed third-party ad networks, tag managers or live affiliate scripts on these pages today.
  • We do not use this site to collect payment card or identity documents.

What may still be visible to others

If you host or open these files on the public internet, the company that serves the pages (for example a static host) will typically see ordinary web-server logs such as IP address, browser type and the URL you requested. That is a function of hosting, not of a tracker we added. Your email provider will also see a message if you write to us.

Contact

If you email ahmglobal7@gmail.com, we will use that address only to reply to your question unless you ask us to keep a longer conversation going.

If we later add ads, affiliate links or a paid extra, we will update this page before those features collect anything beyond a normal click-through.
