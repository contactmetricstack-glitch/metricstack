# MetricStack by AHM Global

Free, no-signup calculators. Static HTML, CSS and JavaScript only — no framework, no backend, no tracking.

Open `index.html` locally, or serve the folder:

    python3 -m http.server 8080

Run the calculator tests:

    node tests/test_calculators.js

Prices and fee schedules in the tools were checked on 14 November 2026. After go-live, update the host in `sitemap.xml` and `robots.txt` (they currently assume `https://contactmetricstack-glitch.github.io/metricstack/`).
